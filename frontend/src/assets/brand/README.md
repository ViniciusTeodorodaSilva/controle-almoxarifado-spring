# Assets oficiais B&S Engenharia

Colocar aqui os PNGs oficiais fornecidos pelo usuário:

- bes-logo-sidebar.png: marca compacta, fundo transparente e contraste adequado ao fundo escuro #182733. Área máxima exibida: 142 × 42 px; fornecer preferencialmente resolução 2x.
- bes-logo-full.png: logo completa oficial, preferencialmente transparente. Reservada para uso futuro em login, documentos, relatórios e páginas institucionais.

Não há PNG oficial no repositório nesta rodada. A aplicação mantém BES textual como fallback. Brand.jsx aceita variant="sidebar" ou variant="full". Importação via glob Vite permite adicionar os arquivos sem editar o componente; reiniciar o Vite/rebuild após colocá-los. Não remover fundo, redesenhar ou inventar a marca. Nenhuma tela de login foi criada.
